# Отчёт по лабораторной работе №3: линейные модели

## Данные и подготовка

Для регрессии использован `Student_Performance.csv`: 10 000 наблюдений, 5 признаков. Целевой столбец — `Performance Index`. Значения `Extracurricular Activities`: `Yes` → 1, `No` → 0. Данные разделены на 8000 объектов для обучения и 2000 для теста (80/20, `random_state=42`). Для собственного градиентного спуска признаки стандартизируются с использованием **только обучающей выборки**. Полученные веса и смещение переводятся обратно в исходный масштаб признаков.

Для классификации использован `german.csv`: 1000 объектов и 20 числовых признаков. Цель — `Creditability` (0 или 1), первый столбец. Разделение стратифицированное: 800 train и 200 test (80/20, `random_state=42`). Среднее и стандартное отклонение для стандартизации вычисляются только на train. Все модели оцениваются на одном и том же разделении.

## Гипотезы и эксперименты

1. Линейная регрессия обучается собственным **пакетным градиентным спуском** по MSE (`learning_rate=0.05`, `epochs=800`). На каждой эпохе градиенты рассчитываются по всей обучающей выборке. MSE на обучении уменьшилась с **299.828** после первой эпохи до **4.170** после последней.
2. Собственная бинарная логистическая регрессия использует сигмоиду и пакетный градиентный спуск по binary cross-entropy (`learning_rate=0.1`, `epochs=1000`). BCE уменьшилась с **0.6041** до **0.4821**. Для устойчивости логарифмов значения вероятностей ограничиваются допустимым диапазоном.
3. Контрактная функция `compare_classical_models` сравнивает на одном split **собственную логистическую регрессию**, `DecisionTreeClassifier(max_depth=5, random_state=42)` и `KNeighborsClassifier(n_neighbors=7)`. Дополнительно в скрипте эксперимента отдельно оценивается готовая `sklearn.LogisticRegression(max_iter=1000, random_state=42)` как справочная модель. Масштабирование для собственной модели выполняется внутри её реализации, а для KNN и справочной sklearn-модели — через `StandardScaler`, обученный только на train. Дерево работает на исходных признаках.

## Метрики

**Регрессия:** test MSE = **4.082628**.

| Классификатор | ROC-AUC | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| Собственная логистическая регрессия | 0.808095 | 0.770000 | 0.801282 | 0.892857 | 0.844595 |
| sklearn LogisticRegression | 0.808571 | 0.770000 | 0.801282 | 0.892857 | 0.844595 |
| Decision Tree | 0.678095 | 0.690000 | 0.830508 | 0.700000 | 0.759690 |
| KNN | 0.781548 | 0.760000 | 0.787500 | 0.900000 | 0.840000 |

ROC-AUC вычислен по вероятностям класса 1, а остальные показатели — по бинарным предсказаниям с порогом 0.5.

## Выводы

Собственная логистическая регрессия показала ROC-AUC **0.808095**. Это почти тот же результат, что у готовой реализации sklearn (**0.808571**). Разница небольшая, потому что обе модели обучают линейную границу решения, но алгоритмы оптимизации и настройки различаются. Собственная модель превзошла дерево и KNN по ROC-AUC. Дерево имеет более низкий ROC-AUC (**0.678095**); одиночное дерево может хуже обобщать данные. KNN достиг ROC-AUC **0.781548** и Recall **0.9000**, то есть нашёл немного больше положительных объектов, но уступил логистической модели по ROC-AUC. Итоги зависят от конкретного разбиения и настроек.

## Воспроизводимость

1. Установить `numpy`, `pandas`, `scikit-learn`.
2. Запустить `python run_experiments.py` из корня репозитория.
3. Скрипт создаёт `experiment_results.json` с измеренными метриками.

Для обоих наборов данных: `test_size=0.2`, `random_state=42`; для `german.csv` также `stratify=labels`. Градиентный спуск стартует с нулевых весов и фиксированного начального смещения, поэтому результаты воспроизводимы. Для проверки функций можно выполнить `python -m pytest -q`.
